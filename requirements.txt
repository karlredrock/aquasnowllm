# AquaSnowLLM has NO required third-party packages: it uses only the Python
# 2.7 standard library (urllib2, ssl, json, socket) plus a Qt 4 binding.
#
# Qt 4 binding (required -- install the matching binary package):
#   MacPorts (Snow Leopard):  sudo port install py27-pyqt4
#   Homebrew (10.10-10.14):   brew install python2 pyqt@4
#   Official .dmg (riverbankcomputing.com) also works for Apple's python2.7
#
# Optional, not used by default (the client speaks urllib2/ssl directly):
#   requests
#
# Packaging (macOS only).  BOTH of these are needed to freeze the app --
# py2app alone produces a bundle with no Qt 4 inside it:
#   sudo port install py27-pyqt4
#   sudo port install py27-py2app
#
# If you install py2app with pip instead, pin 0.28.9:
#   python2.7 -m pip install "py2app==0.28.9"
# 0.28.10 is NOT usable -- despite listing a Python 2.7 classifier its
# metadata says requires_python >= 3.10, so pip refuses it on 2.7.
